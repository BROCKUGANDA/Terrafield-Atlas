# API gateway (Kong) — TerraField Atlas

The developer API is described by the live OpenAPI 3.1 document at
`GET /api/v1/openapi.json`. Kong's declarative configuration in
`deploy/kong/terrafield-openapi.yaml` is generated from that document with
decK, then rate-limited and correlation-tagged at the gateway.

## Generate and validate

```bash
curl -fsS https://terrafieldatlas.us/api/v1/openapi.json -o /tmp/terrafield-openapi.json
jq '.servers=[{"url":"https://terrafieldatlas.us/api/v1","description":"Production"}]' \
  /tmp/terrafield-openapi.json > /tmp/terrafield-openapi-prod.json
deck file openapi2kong -s /tmp/terrafield-openapi-prod.json \
  -o deploy/kong/terrafield-openapi.yaml
deck file validate deploy/kong/terrafield-openapi.yaml
```

The committed file was produced this way; the service points directly at
`terrafieldatlas.us:443` (no stale upstream targets) and carries:

- `rate-limiting`: 120 requests/minute and 1,000/hour per consumer/IP.
- `correlation-id`: UUID `X-Correlation-Id` echoed downstream.

## Run Kong DB-less and test through it

```bash
docker run -d --name tf-kong -p 127.0.0.1:18000:8000 \
  -v "$PWD/deploy/kong/terrafield-openapi.yaml:/kong/declarative/kong.yaml:ro" \
  -e KONG_DATABASE=off \
  -e KONG_DECLARATIVE_CONFIG=/kong/declarative/kong.yaml \
  kong:3.9

curl -i -X POST http://127.0.0.1:18000/oauth/token \
  -H 'content-type: application/x-www-form-urlencoded' \
  --data 'grant_type=client_credentials&client_id=x&client_secret=y'
```

## Verified 2026-11-26

Kong 3.9, DB-less, declarative config generated by decK 1.65.1 and accepted by
`deck file validate` (exit 0):

| Request through Kong | Result |
| --- | --- |
| `POST /oauth/token` with invalid credentials | `401` from the application |
| `GET /developer/farms` without credentials | `401` from the application |
| Rate-limit headers | `X-RateLimit-Limit-Minute: 120`, `X-RateLimit-Remaining-Minute`, `RateLimit-Reset` |

The gateway adds rate limiting and correlation headers without weakening the
application's own authentication, tenant checks or quotas. Kong is **not** part
of the production request path; Caddy + Cloudflare terminate the public edge.
